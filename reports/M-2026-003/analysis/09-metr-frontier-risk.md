# METR — Frontier Risk Report

- 자료: `metr-frontier-risk-report` (research_org, 위키 재사용 원문)
- 원문: `/work/llm-wiki/raw/mission-m-2026-002/metr-frontier-risk-report.md`.

## 핵심 주장
1. METR은 2026-02부터 frontier AI developer 내부 agent의 misalignment risk를 평가하는 pilot을 수행했고, 참여자는 Anthropic·Google·Meta·OpenAI라고 보고한다. [원문: l.32–40]
2. 이 평가는 model-specific이 아니라 entity-based이며 공개 릴리스에 묶이지 않고 주기적 반복을 목표로 한다. [원문: l.40]

## 근거·방법론
- assessment window는 2026-02-16~2026-03-16이다. [원문: l.28]
- 참여사가 자료를 제공하고 METR이 private report를 작성한 뒤, 참여사가 공개 가능한 non-public information을 승인하고 public report를 작성하는 절차다. [원문: l.36–40]

## 정의·수치
- 평가 기간: 2026-02-16~2026-03-16(원문이 제시한 날짜 범위). [원문: l.28]
- 참여 기관: 4곳. [원문: l.34]

## 한계·검증 이관
- 이 자료는 memory 설계 성능보다 조직 내부 agent misalignment risk의 보조 맥락이다.
- 공개 정보는 참여사 승인 범위로 제한되므로, 관찰 결과를 전체 frontier agent 생태계의 대표 표본으로 해석하지 않는다. [원문: l.36–40]

- **외부 검증 상태 이관(09-2):** entity-based·비공개 릴리스 비연동·주기적 반복 목표라는 평가는 METR의 자체 절차 서술이다. 독립 기관의 방법 감사가 확인되지 않았으므로 검증된 평가 절차로 일반화하지 않는다. [원문: l.40; 검증 기록: verify/verification.md §09-2, §7 잔여 보완 2]
