# LoCoMo — 자료별 분석 노트

- 자료: `locomo-evaluating-very-long-term-conversational-memory` (academic)
- 원문 범위: arXiv Atom 초록만 보존됨. 본 노트의 모든 내용은 초록 범위에 한정됨.

## 핵심 주장
1. 기존 장기 개방형 대화 연구는 최대 5개 세션 맥락에 치우쳐 있어, 매우 장기 대화에서 long-context LLM·RAG의 효능은 충분히 탐색되지 않았다는 문제 제기다. [원문: XML l.16]
2. LoCoMo는 QA·이벤트 요약·멀티모달 대화 생성으로 장기기억을 평가하며, LLM은 긴 대화의 장거리 시간·인과 동학 이해에 어려움이 있고 long-context/RAG도 인간 성능에 크게 못 미친다고 보고한다. [원문: XML l.16]

## 근거·방법론
- 페르소나와 시간 이벤트 그래프에 근거한 LLM-agent 대화를 생성하고, 인간 주석자가 장거리 일관성 및 이벤트 그래프 접지를 검증·편집한 machine-human 파이프라인이다. [원문: XML l.16]
- 각 대화는 평균 300턴·9K 토큰이며 최대 35세션을 포괄한다. [원문: XML l.16]

## 정의·수치
- LoCoMo: 매우 장기 대화의 장기기억 평가 벤치마크/데이터셋. [원문: XML l.16]
- 300 turns, 9K tokens (평균), up to 35 sessions. [원문: XML l.16]

## 한계·검증 이관
- 보존본이 초록이므로 모델별 점수·인간 대비 격차의 정확한 크기·실험 조건은 추출 불가다. 이 수치를 설계 성능 근거로 사용하려면 논문 본문 확인이 필요하다.
- `LongMemEval` 및 `MemoryAgentBench`와 평가 과업·단위가 다르므로 점수 직접 비교 금지(교차검증 단계 이관).
- **외부 검증 상태 이관(01-1):** ‘기존 연구가 최대 5세션에 치우쳤다’는 문헌 범위 주장은 이 초록의 문제 제기다. 선행연구 전수 범위의 독립 검토 없이 사실 결론 또는 설계 우위 근거로 사용하지 않는다. [원문: XML l.16; 검증 기록: `verify/verification.md` §01-1, §7 잔여 보완 2]
