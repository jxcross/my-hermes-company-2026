<p>Gemini Nano lets you deliver rich generative AI experiences without needing
a network connection or sending data to the cloud. On-device AI is a great
solution for use-cases where low cost, and privacy safeguards are your primary
concerns.</p>

<p>For on-device use-cases, you can take advantage of Google&#39;s Gemini Nano
foundation model. <a href="https://android-developers.googleblog.com/2023/12/a-new-foundation-for-ai-on-android.html">Gemini Nano runs in Android&#39;s AICore system service</a>,
which leverages device hardware to enable low inference latency and keeps the
model up-to-date.</p>

<h2 id="ml_kit_genai_apis" data-text="ML Kit GenAI APIs" tabindex="-1">ML Kit GenAI APIs</h2>

<p>ML Kit&#39;s GenAI APIs harness the power of Gemini Nano to help your apps perform
tasks. These APIs provide out-of-the-box quality for popular use cases through
a high-level interface. The ML Kit GenAI APIs are built on top of AICore, an
Android system service that enables on-device execution of GenAI foundation
models to facilitate features such as enhanced app functionality and
improved user privacy by processing data locally. <a href="https://developers.google.com/ml-kit/genai" class="external">Learn more</a>.</p>
<aside class="note"><strong>Note:</strong><span> The <a href="https://developers.google.com/ml-kit/genai-terms">ML Kit GenAI API Additional Terms of Service</a> apply to the use of the
GenAI APIs. Developers are solely responsible for the safety of their API
client and their app&#39;s user experience.</span></aside>
<h3 id="key-features" data-text="Key features" tabindex="-1">Key features</h3>

<p>The ML Kit GenAI APIs support the following features:</p>

<ul>
<li><a href="https://developers.google.com/ml-kit/genai/prompt/android" class="external"><strong>Prompt</strong></a>: Generate text content based on a custom
text-only or multimodal prompt.</li>
<li><a href="https://developers.google.com/ml-kit/genai/summarization/android" class="external"><strong>Summarization</strong></a>: Summarize articles or conversations as a
bulleted list.</li>
<li><a href="https://developers.google.com/ml-kit/genai/proofreading/android" class="external"><strong>Proofreading</strong></a>: Proofread short chat messages.</li>
<li><a href="https://developers.google.com/ml-kit/genai/rewriting/android" class="external"><strong>Rewriting</strong></a>: Rewrite short chat messages in different tones
or styles.</li>
<li><a href="https://developers.google.com/ml-kit/genai/image-description/android" class="external"><strong>Image Description</strong></a>: Generate a short description of a
given image.</li>
<li><a href="https://developers.google.com/ml-kit/genai/speech-recognition/android" class="external"><strong>Speech Recognition</strong></a>: Transcribe spoken audio to text.</li>
</ul>

<h2 id="architecture" data-text="Architecture through AICore" tabindex="-1">Architecture through AICore</h2>

<p>As a system-level module, you access AICore through a series of APIs in order to
run inference on-device. In addition, AICore has several built-in safety
features, ensuring a thorough evaluation against our safety filters. The
following diagram outlines how an app accesses AICore to run Gemini Nano
on-device.</p>

<figure>
  <img src="/static/images/ai/aicore/gemini-architecture-google-ai-edge-sdk.png"
    width="600px"
    alt="A diagram showing how an Android app uses the Google AI Edge SDK to
    access AICore, where Gemini Nano, LoRA, and safety features are managed
    and run on hardware accelerators." />
  <figcaption><b>Figure 1.</b> AICore serves as the interface between your
    app and the Gemini Nano model, managing model updates and safety while
    leveraging on-device hardware.</figcaption>
</figure>

<h2 id="keep-data-private" data-text="Keep user data private and secure" tabindex="-1">Keep user data private and secure</h2>

<p>On-device generative AI executes prompts locally, eliminating server calls.
While this removes network latency, inference speed depends on device hardware.
This approach enhances privacy by keeping sensitive data on the device,
enables offline functionality, and reduces inference costs.</p>

<p>AICore adheres to the <a href="https://arxiv.org/abs/2209.10317">Private Compute Core</a> principles, with the following
key characteristics:</p>

<ul>
<li><strong>Restricted Package Binding</strong>: AICore is isolated from most other packages,
with limited exceptions for specific system packages. Any modifications to
this allowed list can only occur during a full Android OTA update.</li>
<li><strong>Indirect Internet Access</strong>: AICore does not have direct internet access.
All internet requests, including model downloads, are routed through the
open-source <a href="https://github.com/google/private-compute-services">Private Compute Services</a> companion APK. APIs within Private
Compute Services must explicitly demonstrate their privacy-centric nature.</li>
</ul>

<p>Additionally, AICore is built to isolate each request and doesn&#39;t store
any record of the input data or the resulting outputs after processing
them to protect user privacy. Read the blog post
<a href="https://android-developers.googleblog.com/2024/10/introduction-to-privacy-and-safety-gemini-nano.html">An Introduction to Privacy and Safety for Gemini Nano</a> to learn more.</p>

<figure>
  <img src="/static/images/ai/aicore-architecture.png"
    alt="A detailed architecture diagram of AICore showing the request flow:
    API surface, input processing with safety signals, feature configuration,
    runtime with model weights and LoRAs, and output processing with safety
    signals. It also shows model downloads via Private Compute Services." />
  <figcaption><b>Figure 2.</b> The AICore architecture manages input and
    output safety, request processing, and model weights to provide a secure
    environment for on-device AI.</figcaption>
</figure>

<h2 id="benefits-accessing" data-text="Benefits of accessing AI foundation models with AICore" tabindex="-1">Benefits of accessing AI foundation models with AICore</h2>

<p>AICore enables the Android OS to provide and manage AI foundation models.
This significantly reduces the cost of using these large models in your app,
principally due to the following:</p>

<ul>
<li><strong>Ease of deployment</strong>: AICore manages the distribution of Gemini Nano and
handles future updates. You don&#39;t need to worry about downloading or updating
large models over the network, nor impact on your app&#39;s disk and runtime
memory budget.</li>
<li><strong>Accelerated inference</strong>: AICore leverages on-device hardware to accelerate
inference. Your app gets the best performance on each device, and you don&#39;t
need to worry about the underlying hardware interfaces.</li>
</ul>
