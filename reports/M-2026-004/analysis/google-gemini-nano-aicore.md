## 2. 핵심 주장 (저자/문서의 주장)

1. **Gemini Nano는 네트워크 연결이나 클라우드 전송 없이 풍부한 생성형 AI 경험을 제공할 수 있다.** 문서는 온디바이스 AI를 비용과 프라이버시 보호가 핵심 관심사인 용도에 적합한 해법으로 제시한다. 이는 문서의 제품·설계상 주장이지, 본문 내 비교 실험으로 검증된 성능 결론은 아니다. (원문 8,609–8,612행)
2. **Gemini Nano는 Android의 AICore 시스템 서비스에서 동작하며, AICore는 디바이스 하드웨어를 활용해 낮은 추론 지연시간과 모델 최신 상태를 가능하게 한다.** (원문 8,614–8,617행)
3. **ML Kit GenAI API는 Gemini Nano를 고수준 인터페이스로 노출하고 AICore 위에 구축되어, 로컬 데이터 처리로 앱 기능과 사용자 프라이버시를 개선한다고 문서는 설명한다.** (원문 8,621–8,626행)
4. **AICore는 앱과 Gemini Nano 사이의 인터페이스로서 모델 업데이트·안전을 관리하고, 온디바이스 하드웨어를 활용한다.** 이는 그림 1의 캡션과 alt 텍스트가 서술하는 아키텍처 역할이다. (원문 8,655–8,663행)
5. **온디바이스 생성 AI는 서버 호출을 없애고, 민감 데이터를 기기에 유지하며, 오프라인 기능과 추론 비용 절감을 제공한다고 문서는 주장한다.** 단, 추론 속도는 기기 하드웨어에 좌우된다고 함께 한정한다. (원문 8,666–8,671행)
6. **AICore는 Private Compute Core 원칙을 따른다고 문서는 주장하며, 제한된 패키지 바인딩·간접 인터넷 접근·요청 격리·처리 후 입출력 기록 미보존을 프라이버시 특성으로 제시한다.** (원문 8,673–8,688행)
7. **AICore의 모델 배포·업데이트 관리와 하드웨어 가속은 대형 모델을 앱에서 사용하는 비용을 크게 낮추며, 앱의 디스크·런타임 메모리 예산 및 하드웨어 인터페이스 부담을 줄인다고 문서는 주장한다.** (원문 8,702–8,715행)

## 3. 근거 및 원문상 관찰 (주장과 구분)

- **API 기능 목록:** 문서는 ML Kit GenAI API가 프롬프트(텍스트 전용 또는 멀티모달 입력 기반 텍스트 생성), 기사·대화의 글머리표 요약, 짧은 채팅 메시지 교정 및 스타일/톤 재작성, 이미지의 짧은 설명 생성, 음성의 텍스트 전사를 지원한다고 열거한다. 이는 지원 기능에 대한 문서의 명시적 관찰이며, 품질·정확도·지원 기기 범위를 측정한 결과는 아니다. (원문 8,632–8,645행)
- **시스템 경계의 명시:** 본문은 AICore를 시스템 수준 모듈로 규정하고, 온디바이스 추론을 위해 일련의 API를 통해 접근한다고 설명한다. 또한 내장 안전 기능이 안전 필터에 대한 철저한 평가를 보장한다고 서술한다. (원문 8,647–8,653행)
- **그림 1에서 텍스트로 확인 가능한 흐름:** alt 텍스트는 Android 앱이 Google AI Edge SDK를 통해 AICore에 접근하고, 그 안에서 Gemini Nano·LoRA·안전 기능이 관리되며 하드웨어 가속기에서 실행된다고 설명한다. 이미지는 직접 분석하지 않았으므로 구성 요소의 추가 관계·배치·수치는 알 수 없다. (원문 8,655–8,660행)
- **프라이버시 제약의 구체화:** 제한된 패키지 바인딩의 허용 목록 변경은 전체 Android OTA 업데이트 때만 가능하며, AICore는 직접 인터넷에 접근하지 않는다. 모델 다운로드를 포함한 인터넷 요청은 Private Compute Services 동반 APK를 통해 라우팅된다고 서술한다. (원문 8,677–8,683행)
- **그림 2에서 텍스트로 확인 가능한 흐름:** alt 텍스트·캡션은 API 표면, 안전 신호를 포함한 입력/출력 처리, 기능 구성, 모델 가중치·LoRA가 있는 런타임, Private Compute Services 경유 모델 다운로드를 언급한다. 이는 그림의 텍스트 설명 범위이며, 처리 순서의 성능·보안 효과나 세부 구현은 이 원문만으로 확인되지 않는다. (원문 8,691–8,700행)
- **개발자 책임의 명시:** ML Kit GenAI API 추가 서비스 약관이 적용되고, API 클라이언트 및 앱 사용자 경험의 안전성은 개발자가 전적으로 책임진다고 적혀 있다. (원문 8,627–8,629행)

## 4. 수치·정의·방법론

### 수치

- 본문은 벤치마크, 지연시간, 처리량, 비용 절감률, 모델 크기, 지원 기기 수, 안전성 평가 점수 같은 **정량 실험 결과를 제시하지 않는다**. 따라서 ‘낮은 지연시간’, ‘비용을 크게 낮춤’, ‘최고 성능’은 수치화·재현 조건이 첨부되지 않은 문서의 서술이다. (원문 8,614–8,617행, 8,704–8,715행)
- 본문에 명시된 문서 갱신 날짜는 `2026-04-02 UTC`이다. (원문 8,777–8,780행)

### 문서 내 정의·구성

- **Gemini Nano:** 온디바이스 사용 사례를 위한 Google의 foundation model로 소개된다. (원문 8,614–8,617행)
- **AICore:** GenAI foundation model의 온디바이스 실행을 가능하게 하는 Android 시스템 서비스이며, 앱과 Gemini Nano 사이의 인터페이스로 설명된다. (원문 8,621–8,626행; 8,661–8,663행)
- **ML Kit GenAI API:** Gemini Nano의 기능을 앱 작업에 활용하도록 하는 고수준 인터페이스이며 AICore 위에 구축된 API로 제시된다. (원문 8,621–8,626행)
- **Restricted Package Binding:** AICore가 대부분의 다른 패키지와 격리되고 특정 시스템 패키지에 한해 예외가 있으며, 허용 목록 변경은 전체 OTA 때만 가능하다는 특성이다. (원문 8,677–8,679행)
- **Indirect Internet Access:** AICore에 직접 인터넷 접근이 없고, 모든 인터넷 요청은 Private Compute Services 동반 APK를 거친다는 특성이다. (원문 8,680–8,683행)

### 방법론/검증 설계

- 이 자료는 Android 개발자용 기능·아키텍처 문서다. 독립적인 실험 설계, 표본, 데이터셋, 기기 사양, 모델 버전·정밀도, 비교 기준, 측정 절차, 통계 분석은 본문에 제시되지 않는다.
- 따라서 본문은 **제품 인터페이스·설계 특성의 설명**으로는 읽을 수 있으나, 성능·비용·프라이버시 효과의 재현 가능한 실증 방법론으로는 사용할 수 없다. 이는 원문에 해당 방법 세부가 없다는 범위 한정 판단이다.

## 5. 원문 한계 및 확인 필요 항목

1. **성능 검증 부재:** 낮은 지연시간·하드웨어 가속·기기별 최고 성능이라는 표현이 있으나, 기기, 모델 빌드, 입력 길이, 정밀도, 런타임, 측정 지표·절차가 없다. 실제 지연시간·처리량·메모리·전력 및 기기 간 편차는 별도 확인이 필요하다. (원문 8,614–8,617행; 8,668–8,670행; 8,713–8,715행)
2. **비용 주장 정량화 부재:** 서버 호출 제거와 비용 감소가 서술되지만, 어떤 비용(추론, 네트워크, 배포, 저장공간 등)인지의 산정식·기준선·감소폭은 제공되지 않는다. (원문 8,668–8,671행; 8,704–8,712행)
3. **지원 범위 불명확:** 기능 목록은 있으나 Android 버전, 기기/칩셋, 지역·언어, 모델 변형, 오프라인 가용성 조건, 기능별 입력 제약은 이 원문 본문에서 확인되지 않는다. (원문 8,632–8,645행)
4. **안전성의 측정 근거 부재:** AICore의 안전 필터 평가·입출력 안전 관리가 기술되지만, 필터 기준·오류율·평가 데이터·한계·개발자 제어 범위는 없다. 또한 앱 안전성 책임은 개발자에게 있다고 명시한다. (원문 8,649–8,653행; 8,627–8,629행; 8,697–8,699행)
5. **프라이버시 주장 범위:** 입력과 결과를 처리 후 기록하지 않는다는 문구는 있으나, 로그·텔레메트리·오류 보고·모델 다운로드 메타데이터·호출자 앱의 데이터 처리까지 포괄하는지 원문만으로 확정할 수 없다. 직접 인터넷 접근이 없어도 모델 다운로드를 포함한 요청은 Private Compute Services를 경유한다고 서술된다. (원문 8,680–8,688행)
6. **그림 접근 한계:** 두 아키텍처 그림은 alt 텍스트와 캡션만 확인했다. 그림 내 세부 화살표·주석·배치에서만 알 수 있는 내용이나 이미지 자체의 추가 정보는 확인하지 않았다. (원문 8,655–8,664행; 8,691–8,700행)
7. **문서 시점·변경 이력:** 마지막 갱신일은 표시되지만, 최초 게시일, 특정 Gemini Nano/AICore 버전, 변경 이력은 원문 본문에 없다. 인벤토리의 `published_year: 2026`은 수집 메타데이터이므로 최초 게시 시점의 독립 근거로 취급하지 않는다. (원문 8,777–8,780행; `raw/sources.yaml` 58–64행)
